# Changelog

## 1.0.0

- Mobile-first feature flags for .NET MAUI on iOS and Android
- `FeatureFlags.IsEnabled` / `IsEnabledAsync` with a MAUI targeting cascade
- Remote JSON configuration, local fallbacks, and an offline file cache
- Device, OS / version, country, user, and app-version targeting
- Sticky percentage rollout, kill switches, expiration, and Dev/Staging/Production
- Runtime overrides for QA and a sample that walks through each targeting rule
